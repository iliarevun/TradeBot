# 🤖 TradeBot v2 — Telegram Trading Bot + Mini App

## 📦 Структура проекту
```
trading_bot_v2/
├── bot.py              — головний файл бота
├── analyzer.py         — технічний аналіз (5 стратегій)
├── data_provider.py    — завантаження даних (3 провайдери)
├── messages.py         — форматування повідомлень
├── config.py           — конфігурація (токен, ключі API)
├── requirements.txt    — залежності Python
└── webapp/
    └── index.html      — Telegram Mini App (графіки, журнал, калькулятор)
```

## 🚀 Швидкий старт (5 хвилин)

### Крок 1 — Отримайте токен бота
1. Відкрийте @BotFather у Telegram
2. `/newbot` → введіть ім'я → отримайте токен

### Крок 2 — Отримайте безкоштовний API ключ для даних
**Рекомендовано: Twelve Data** (800 запитів/день безкоштовно)
1. Зайдіть на https://twelvedata.com
2. Зареєструйтеся → отримайте ключ у Dashboard

### Крок 3 — Налаштуйте config.py
```python
BOT_TOKEN = "7123456789:AAHxxx..."
TWELVE_DATA_KEY = "your_key_here"
WEBAPP_URL = "https://your-site.com"  # (необов'язково для початку)
```

### Крок 4 — Встановіть залежності
```bash
pip install -r requirements.txt
```

### Крок 5 — Запустіть бота
```bash
python bot.py
```

## 📱 Telegram Mini App — Налаштування

Mini App — це веб-додаток, що відкривається прямо в Telegram.

### Варіант 1: GitHub Pages (безкоштовно, найпростіше)
1. Створіть репозиторій на github.com
2. Завантажте папку `webapp/` у репозиторій
3. Settings → Pages → Branch: main → Save
4. Отримаєте URL: `https://username.github.io/repo-name/`
5. Вставте у `config.py`: `WEBAPP_URL = "https://username.github.io/repo-name/"`

### Варіант 2: Netlify (безкоштовно, drag & drop)
1. Зайдіть на netlify.com
2. Перетягніть папку `webapp/` на сторінку
3. Отримаєте URL автоматично

### Варіант 3: Vercel (безкоштовно)
```bash
npx vercel webapp/
```

### Важливо: HTTPS обов'язковий!
Telegram вимагає HTTPS для Mini App. GitHub Pages і Netlify надають HTTPS автоматично.

## ⚙️ Параметри config.py

```python
EMA_FAST   = 21      # Швидка EMA (синя лінія)
EMA_SLOW   = 50      # Повільна EMA (жовта лінія)
EMA_TREND  = 200     # Трендова EMA
RSI_PERIOD = 14      # Період RSI
RSI_OVERSOLD   = 30  # Рівень перепроданості
RSI_OVERBOUGHT = 70  # Рівень перекупленості
ATR_SL_MULTIPLIER = 1.5  # SL = ATR × 1.5
MIN_RR = 2.0         # Мінімальний Risk:Reward
```

## 📊 Що аналізує бот

**Індикатори:** EMA 21/50/200 · RSI 14 · ATR 14 · MACD · Bollinger Bands

**Свічкові паттерни:**
- Пін-бар (бичачий/ведмежий)
- Поглинання (бичаче/ведмеже)
- Доджі · Inside Bar
- Ранкова зірка / Вечірня зірка
- Молот / Падаюча зірка

**Стратегії:**
1. Відбій від рівня підтримки/опору
2. Пробій рівня + ретест
3. Тренд + корекція до EMA
4. Діапазонна торгівля (флет)
5. EMA 21×50 Crossover + Price Action
